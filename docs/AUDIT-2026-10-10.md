# Quality audit, 10 Oct 2026 (after stage E)

Six reviewers read the whole app in parallel (AI and Talk, data and security, memory, promises/planner/writing,
backup/settings/bench, the Compose screens), about 80 findings in all. Every finding below was checked against
the code before anything was changed. Branch: `claude/app-quality-audit-okaiym`, on top of stage E.

Checks run on the build machine: `bash tools/check_all.sh` (32 mutations, 0 survive), `bash
tools/forbidden_patterns.sh`, the 102 pure-Kotlin core tests and the 22 AI wire/failover tests with the plain
Kotlin compiler, and the memory exam (unchanged at 62.9%). The Android build, lint, unit tests and the emulator
tests run on GitHub CI for every push.

## Fixed

### Could lose data, leak privacy, or break a rule in CLAUDE.md
| What was wrong | Fix |
|---|---|
| Turning the phone ran the "startup" repair again: a reply still being written was marked cut off, and running jobs were put back to pending (a second paid call) | Once per process; only jobs untouched for 30 minutes are requeued |
| App lock: after the phone killed the app in the background, reopening it from Recents skipped the lock (saved screen state said "unlocked") | Unlock lives only in the running process; decided at once on return; fails closed |
| The database key was saved asynchronously; a crash right after first launch left an encrypted database with no key | Saved with `commit()` before use; a missing key for an existing database fails plainly |
| Sending while a reply streamed garbled both replies and left one stuck "streaming" forever | One reply at a time (Send waits, the service refuses a second), cancelled replies settle as interrupted |
| Forget this conversation erased the tombstone of a note they had deleted, so it could be learned again (rule 5) | Tombstones stay |
| The same CHECKIN_FACTS line cited daily raised a note to "likely" and "seen N times" with no new occurrence | Only evidence the note does not have yet counts |
| A count was accepted as any substring: "2 answered of 2" passed as a copy of "12 answered of 20" (rules 2, 3) | Whole-token match on one line; contract, vector, mutation and Kotlin changed together |
| Reflection could rewrite a confirmed profile entry and keep "Confirmed by you" | A changed value is unconfirmed until they tap |
| Export everything (unencrypted) held deleted notes' text and off-the-record conversations in its JSON | Left out, with the app's housekeeping tables |
| Reviews and letters could quote off-the-record conversations | Excluded |
| A backup from before any schema change (v1 to v2 already happened) could never be restored | Older backups restore (every migration so far only adds) |
| After a restore, an old alarm could ring a different restored promise days early; Settings claimed a backup this phone never made | Alarms cleared first; this phone's backup record kept |

### Speed
- Talk re-queried cards about once a second while streaming; Plan and What I know rebuilt on the main thread;
  replacing a search-index row read the whole index. All fixed.

## Fixed in the follow-up (11 Oct 2026, branch `claude/audit-form-issues-u1v6hu`)

The seven items this audit left open were all fixed, at the owner's request ("fix everything in the audit form").

| Item | Fix |
|---|---|
| 1. **SQLCipher library** deprecated, native code not built for 16 KB memory pages | Moved to `net.zetetic:sqlcipher-android:4.6.1` (approved by the owner as part of the request). Same SQLCipher 4 file format, same 32-byte key, so the existing database opens unchanged |
| 2. **Sunday letter alert default** | On (silent), the spec's recommendation. A phone that already saved the switch keeps its choice. Settings shows "Notifications are off for Clarity" with a tap to allow them while the alert is on and notifications are off |
| 3. **Gardening was not built** | `GardeningJob` runs from the writing worker: once a month, and once more within a week while any kind of note is at its cap of 15. Code writes the input, including "quiet 60+ days". `MemoryRepository.applyGardening` re-checks every note as it is now: their edits, confirmations and deletions win, nothing comes back close to a deleted note, a merge keeps every evidence row, and confidence never rises |
| 4. **Erase everything** | Settings, Your data, confirmed by typing ERASE. Alarms, notifications and background jobs are cancelled, the backup folder grant is released, the sealed key and secrets are cleared, then Android clears all app data and closes the app. Backups in their folder stay |
| 5. **Large-database backups** | Backup format 2 streams: rows to JSON to gzip to 64 KiB AES-GCM chunks, each bound to the header, its position and whether it is last. Restore inserts rows as they are read, in one transaction that commits only after the last chunk checked out. Format 1 backups still restore. Export streams its JSON too |
| 6. **Meaning search read up to 60,000 vectors per message** | `VectorCache` keeps the vectors in memory as int8 (384 bytes each) and reads only new rows after a change. The best candidates are scored again exactly from the stored floats, so results are unchanged |
| 7. **Smaller items** | The drawer lists every conversation, grouped by day, with search (titles and summaries) and Rename. A backlog's creation day is stored when it is made (schema version 3, `backlog.start_day`, add-only migration). The monthly review waits for the day boundary on the 1st. Anthropic prompt caching is on (system message and the history before the final turn) |

Checks: `bash tools/check_all.sh` and `bash tools/forbidden_patterns.sh` pass. New tests: `GardeningInputTest`,
`VectorIndexTest`, more `BackupFormatTest`, `ReviewTimesTest`, `KnowTextTest` and `WireTest` cases (JVM), and
`GardeningApplyTest`, two new `RestoreTest` cases and a version 2 to 3 `MigrationTest` (emulator). These run on
GitHub CI; nothing was built on this machine.

## What to check on the phone
1. Install the new debug APK over the old app (never uninstall).
2. Talk: send a message, and while the reply is still typing, try to send another. It must say "Wait for this
   reply to finish" and keep what you typed. Turn the phone sideways mid-reply: the reply keeps going (it used
   to show "cut off").
3. App lock: open Clarity, unlock, go home, then open a few heavy apps (or wait for Clarity to be killed), and
   reopen it from Recents after a minute: it must ask for your fingerprint.
4. Plan: pause a target on its goal page; it stays there with Resume. Open a goal and press Back: you return to
   the goal list, not to Talk.
5. Settings, Coach: Test connection still says Connected.
6. After the follow-up: open the app once after installing (the database moves to schema version 3 and the
   new SQLCipher library opens it). Your chats, goals and notes must all still be there.
7. Settings, Your data: Back up now must say "Saved ..., read back and verified". Restore it on a second
   phone or emulator if you can.
8. Talk, the conversations button: every conversation is listed under day headings. Search finds one, and
   Rename keeps your title.
9. Do not try Erase everything unless you mean it: it deletes everything on this phone.
