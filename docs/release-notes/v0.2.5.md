# Clarity 0.2.5: Separate Settings Boxes & Gemini Connection Fix

## How to install
- Install this APK **over** your current app. Do not uninstall first: uninstalling erases your data.
- To check the download, compare its SHA-256 with SHA256SUMS.txt attached here.
- Your existing data, chats, memories, and keys are preserved safely.

## What is new in 0.2.5

### Completely Separate Settings Boxes
- **Dedicated Coach (Chat) Box**: Houses all settings for your primary chat AI—main provider selection, base URL, API key, chat model, thinking levels, test main connection, letter model, and your name.
- **Dedicated Background AI Box**: Completely separate box for background AI tasks (reflection, memory formation, and reviews)—background provider selection, base URL, background API key, model selection with 1-tap chips (`gemini-3.8-flash`, etc.), and independent test background connection button.
- **Clear Separation**: No more mixing of main model settings with background model settings. Each has its own expandable card with full independent controls.

### Gemini Connection & Error Handling Fixes
- **Clear Provider Error Messages**: Fixed an issue where release builds displayed `"The test could not run (b)."` on connection test failures due to R8 minification catching internal exceptions. Errors now bubble up cleanly and display exact provider feedback.
- **Google Gemini Error Parsing**: Google Gemini's OpenAI-compatible endpoint returns errors in a JSON array (`[{"error": ...}]`). The wire parser now properly parses both object and array error envelopes and extracts status and message details.
- **Friendly Key Detection**: Google returns HTTP 400 for invalid API keys instead of HTTP 401; the client now recognizes key error responses and suggests checking the API key directly.
- **Robust Base URL Handling**: Fixed URL routing for Google Gemini endpoints with trailing slashes or path variations so they cleanly resolve to `https://generativelanguage.googleapis.com/v1beta/openai/chat/completions`.

## What to check on your phone
1. In **Settings**:
   - Tap **Coach**: see all chat settings, chat model chips, and **Test main connection**.
   - Tap **Background AI**: see independent background provider, background URL, background API key, model chips (`gemini-3.8-flash`), and **Test background connection**.
2. Tap **Test background connection**: notice clear, descriptive feedback and instant connection verification without any generic `(b)` errors.
