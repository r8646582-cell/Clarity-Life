# Clarity 0.1.3: plans are agreed before their card

## How to install
- Install this APK **over** 0.1.2. Do not uninstall first: uninstalling erases your data.
- To check the download, compare its SHA-256 with SHA256SUMS.txt attached here.

## What changed
- **No more draft plan cards.** When you build a plan with the coach, it first lays the plan out in words
  and asks if this is the plan you want. You can change anything. Only after you say yes does the Save
  plan card appear, as the final version with your changes in it.
- If you dictate the whole plan yourself and ask to save it, that counts as your yes.
- A change you ask for yourself (for example "make the target 2 a day") still gets its card straight away.
- Promises, switches, notes and focuses work as before: the card comes when you have clearly agreed.

## Please check on the phone
Start a **new** Plan and track chat and build a plan. The first reply should describe the plan and ask
you to confirm, with no card. Say yes: the Save plan card should appear under the next reply.
