# Clarity 0.2.2: cost reduction, faster search, tolerant quotes, and background provider

## How to install
- Install this APK **over** your current app. Do not uninstall first: uninstalling erases your data.
- To check the download, compare its SHA-256 with SHA256SUMS.txt attached here.
- Database migration V8 to V9 is applied safely and automatically upon first launch.

## What is new in 0.2.2

### Cost reduction & speed
- **The "no card" signal (`[[cards: none]]`)**: when a reply has no card to offer and does not talk about a button, the coach signals it directly, skipping the secondary card followup and cutting token costs.
- **Incremental memory updates (`NEW_NOTES`)**: new notes learned in conversation are passed incrementally in conversation context without requiring a full frozen prefix rebuild every turn.
- **Single message embedding**: message embeddings are cached during conversation turns, avoiding repeated embedding calls.
- **int8 vector storage**: meaning vectors are quantized to 1 byte per dimension (772 bytes vs 3 KB), speeding up search index loading by 4x.
- **Optimized candidate search**: search queries avoid bulk reads of non-matching table rows, speeding up retrieval.

### Daily use & conversation improvements
- **Talk check-in cards**: log daily check-ins directly from the chat screen with a single tap (`Log: Tax lectures, 3 today`) or update promise statuses (`Done` / `Not done`).
- **Tolerant quote checks**: quotes verified against your messages tolerate punctuation variations, casing, joined consecutive messages, and minor typos without dropping notes, while always preserving your exact words.
- **Improved pattern & memory recall**: irregular verb stemming and calibrated search improve pattern recognition across months (jumping from 60% to 71.7% on memory exams) with 0 memory leaks.
- **Historical pace with effective schedule**: changing a target's schedule no longer skews the answer rate for the preceding 14 days.

### Settings & Provider flexibility
- **Configurable background provider**: set an independent AI provider, endpoint URL, and API key for background jobs (reflections, gardening, letters, reviews) with automatic fallback to your main provider.
- **Per-chat-type thinking levels**: configure thinking intensity per conversation mode (Free talk, Untangle, Decide, Plan).
- **Cost breakdown in Health**: view token usage and costs broken down by job type (`chat`, `card_followup`, `reflection`, `gardening`, `letter`, `review`).

## What to check on your phone
1. Open Health under Settings to see your token and cost breakdown by job.
2. In Settings, AI coach: configure different thinking levels or set an independent background provider if desired.
3. In Talk: when discussing targets, you can log check-ins with one tap on the suggestion card.
