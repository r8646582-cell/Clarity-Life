- To check the download, compare its SHA-256 with SHA256SUMS.txt attached here.
- Your existing data, chats, memories, and keys are preserved safely.

## What is new in 0.3.0

### On-Device Meaning Model & Native Memory Hardening
- **Fixed `embedder_mismatch` on Real Devices**: In int8 quantized neural models, ARM mobile processors (using ARM NEON / XNNPACK) compute dot products with slight numerical differences compared to x86 CPUs. The reference verification check now normalizes reference vectors and uses an appropriate tolerance (`MIN_REFERENCE_COSINE = 0.90`), allowing on-device meaning search to pass and activate on mobile hardware instead of failing with `embedder_mismatch`.
- **Eliminated Native Memory Leaks**: Closed ONNX runtime `SessionOptions` and session instances properly during error recovery, preventing the native memory accumulation (previously up to 408 MB) and drastically improving startup latency.
- **Search & Vector Hygiene**: Removed redundant constructor instantiation in `EmbeddingIndexer` to ensure only the singleton `SearchIndex` instance is used. Cached vectors in `NoteVectors` now return defensive copies.

### AI Wire Protocol & Background Key Isolation
- **Fixed Reflection `http_401` Failure**: Ensured background jobs do not route chat API keys to external background providers if no separate background key is configured. If background provider is unset, tasks cleanly fall back to the primary chat endpoint.
- **True Coroutine Cancellation**: Fixed OkHttp stream cancellation in both OpenAI-compatible and Anthropic clients. When a chat or job coroutine is canceled, the underlying OkHttp call is quietly aborted, completion handles are disposed, and `CancellationException` is cleanly re-thrown instead of misattributed as `stream_broken`.
- **Wire Protocol Improvements**: Handled empty SSE `data:` lines without JSON parsing errors, normalized Anthropic `/v1/messages` URL routing, and aligned finish reason checks (`max_tokens`).

### Core Math, Database & Concurrency Hardening
- **Atomic Background Job Writes**: Wrapped all entity insertions and job state completion calls across `ChapterWriter`, `LetterWriter`, `ReviewWriter`, `StoryWriter`, and `JobClaims.skip()` inside Room transactions (`db.withTransaction { }`), preventing orphaned or inconsistent job rows during process kills.
- **Crash-Proof Date Parsing**: Fixed a potential `NullPointerException` on regex group extraction in `RecallTime` and added bounds checking (1..52 weeks) plus `DateTimeException` guards in `PlanDates`.
- **FTS Query Protection**: Quoted `ref_id` parameters in full-text search delete queries to prevent SQLite syntax errors on hyphenated or composite identifiers.
- **Cleaned Deprecations**: Migrated all deprecated `minBy`/`maxBy` calls to `minByOrNull`/`maxByOrNull` and eliminated redundant conditions in `MemoryRepository`.

### Security, Lifecycle & UI Polish
- **AppLock Security Fix**: Fixed an issue where rotating the screen while on the biometric lock screen could bypass authentication by resetting `unlockedInProcess` on lock and preventing stale `leftAt` updates.
- **Exact Alarms on Android 13–15**: Removed `maxSdkVersion="32"` from `SCHEDULE_EXACT_ALARM` in `AndroidManifest.xml` and wrapped `setExactAndAllowWhileIdle` in `Reminders` with a `SecurityException` fallback to ensure reminders never crash even if exact alarm permissions are revoked by system battery managers.
- **Cryptographic Master Key Erasure**: Implemented `deleteKey()` in `KeystoreCipher` and invoked it during "Erase Everything", permanently removing the master Keystore entry (`clarity_secrets_v1`) from the hardware secure element on full data wipe.
- **Encrypted Backup SAF Compatibility**: Allowed SAF duplicate suffixes like ` (1).cbk` and enforced salt/iv length bounds during backup decryption.
- **Rotation-Proof UI State**: Switched all dialog visibility flags and text inputs across `SettingsScreen`, `TalkScreen`, and `TalkDrawer` to `rememberSaveable`, ensuring dialogs and typed text remain intact when rotating the phone.
- **Clean Restore Confirmation**: Restructured backup restore dialogs so the confirmation dialog replaces rather than stacks over the password prompt.
- **Live Health Updates**: Added `LifecycleResumeEffect` to reload settings and refresh health checks as soon as the user returns to Settings from system permission screens.
